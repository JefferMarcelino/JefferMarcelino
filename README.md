### About Me

Hi, I'm Jeffer, a Data Engineer at Vodacom Mozambique (part of Vodafone Group). I build and operate production data platforms, currently owning a 9-node Apache NiFi cluster that processes about 100,000 files (1.5TB) daily, replacing a legacy vendor data movement tool. I also build the observability stack around it (Grafana, Grafana Alloy, Mimir, Loki) and automate infrastructure with Ansible and AWS CDK.

Right now I'm building XTream Flow, an internal self service portal that abstracts Apache NiFi's REST API so operations teams can manage routine data flows without needing NiFi expertise.

I'm also the founder and lead engineer of two products: [Jeffito](https://jeffito.app/), an AI powered EdTech platform serving 30,000 students, generating structured academic content and quizzes at scale, and [BeLoved](https://www.thebeloved.app/), a platform that generates personalized romantic web pages, integrating multiple payment gateways including Stripe, M-Pesa, and Multicaixa.

Open to connecting, collaborating, or talking shop about data platforms, infrastructure, and observability.
